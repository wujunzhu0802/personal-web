## 本地使用

简历页与个人网站使用原生 HTML、CSS 和 JavaScript，无需安装依赖。直接打开 `index.html` 可阅读原有简历；个人网站运行以下命令构建后预览：

```bash
npm run build
```

再在仓库目录运行：

```bash
python -m http.server 8000
```

随后访问 <http://localhost:8000/dist/> 查看个人网站，访问 <http://localhost:8000> 查看原有简历。个人网站中的「完整简历」会打开同一构建内的简历页。
