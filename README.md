## 本地使用

网页使用原生 HTML、CSS 和 JavaScript，无需安装依赖。直接打开 `index.html` 即可使用，也可以在仓库目录运行：

```bash
python -m http.server 8000
```

随后访问 <http://localhost:8000>。
